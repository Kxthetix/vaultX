# vaultX Demo Notes

This repository contains the demo version of vaultX.

## Demo Goal

The goal of this demo is to show the basic backend structure of an AI-powered VAPT automation platform.

## What Works in This Demo

- Backend API structure
- Scan workflow planning
- Tool integration structure
- Report output structure

## What Is Planned

- Full frontend dashboard
- Production Docker setup
- Authentication
- Database integration
- Advanced AI agent analysis
- PDF report generation

## Safe Testing

Use this project only on:

- Localhost
- Your own lab systems
- Intentionally vulnerable machines
- Systems where you have written permission

Do not test public systems without permission.
